# 手机聊天键盘自适应 · 2026-10-26

手机聊天容器使用 visualViewport 的高度、宽度和顶部偏移，跟随键盘弹出、收起和 Safari 视口平移。桌面保留原布局。仅手机输入区使用 16px，避免 iOS 对小于 16px 的输入自动缩放；聊天正文和桌面输入字体保持原样，不禁用用户手动缩放。

键盘出现时暂时隐藏底部机器/模型说明，聊天区独立滚动。长输入限制在可视高度的 30%，保留发送按钮空间；底部安全区在键盘打开时压缩。长环境说明单行省略。

截图使用实际 /fusion 与虚构 API 数据，模拟 visualViewport 键盘高度和偏移。它们展示布局验证，不是真机 iOS 键盘截图。覆盖空会话、有历史消息、键盘开关、视口偏移、长输入、手动缩放及恢复桌面字号。真机键盘和浏览器自动缩放需部署后在 iPhone 上复核。
