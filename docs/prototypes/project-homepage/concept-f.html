设计原则

不用理解复杂基础设施，也能让 Agent 在正确的地方工作。

01

从自然的对话开始

选择 Agent 和 Project，描述目标。Conversation 负责保留长期上下文。

02

让 Relay 找到执行位置

固定 Runtime 或自动调度，在本地、远程和团队机器间保持相同体验。

03

带着成果回来

查看流式过程，让真正需要交付的文件成为可预览、下载的 Artifact。

Execution infrastructure

Steer 是工作空间，
Relay 是执行网络。

清晰的产品边界让两者可以一起使用，也可以独立集成。应用拥有 Agent 和业务逻辑；Relay 只负责可靠执行。
