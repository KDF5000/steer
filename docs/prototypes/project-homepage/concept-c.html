// Quick start

从一台机器开始。

使用 Docker Compose 启动 Steer 与 Relay Server，再把已有 AI CLI 的机器连接为 Relay Node。服务和工作目录始终由你控制。

阅读部署文档 ↗
terminal — connect a node
curl -fsSL https://raw.githubusercontent.com/
KDF5000/relay/main/install.sh \
  | RELAY_NODE_TOKEN='••••••••' \
    sh -s -- --server https://relay.example.com \
    --install-service
