A continuous way to work

从一句话开始，带着完整成果回来。

01

在对话中描述目标

Agent、Project 和 Conversation 始终关联，不必为每项任务重新解释环境与上下文。

02

在正确的环境中执行

固定到一台 Runtime，或由 Relay 在本地、远程和团队节点中完成调度。

03

沉淀真正有用的成果

运行过程留在 Conversation，可复用的文件作为 Artifact 持久保存并随时重新打开。

Under the workspace

Steer 负责工作体验，Relay 负责可靠执行。

Built for real work

不是一次性 Prompt，而是可持续的工作空间。

从个人开发机到多节点团队部署，保持相同的工作方式和清晰的控制边界。

◌

持久 Conversation

每条消息产生新的 Run，但同一对话持续复用上下文、Project 与 Runtime。

⌁

本地与 Git Project

直接使用已有目录，或由 Relay 准备隔离的 Git Worktree。

◎

精确或自动调度

把 Agent 固定到一台机器，或按 Provider 与能力自动选择 Runtime。

▱

真正可交付的 Artifact

预览、下载和重新访问 Agent 主动产生的持久文件，而不是把日志当作成果。
