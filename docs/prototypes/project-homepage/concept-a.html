一个连续的工作空间

从一句话，到跨机器执行，再到可复用的成果。

01

对话就是工作入口

Conversation、Project 和 Agent 始终保持关联。刷新页面、切换终端，任务上下文依然连续。

02

在合适的机器上执行

固定到一台 Runtime，或让 Relay 自动调度。开发机、服务器与远程节点都可以成为执行环境。

03

留下真正有用的结果

对话负责过程，Artifact 负责交付。预览、下载并重新打开 Agent 生成的持久文件。

Powered by Relay

你的 Agent，运行在你的机器上。

Relay 负责 Runtime 发现、调度、工作区准备、事件流与可靠执行；Steer 专注于对话、项目与协作体验。
