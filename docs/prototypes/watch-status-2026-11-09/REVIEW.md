# Watch 状态页方案 · 2026-11-09

本轮提供三种可操作的界面提案，供用户选择。没有修改 native App，也没有构建或安装新版本。

## 共同行为

- 四项核心统计一屏显示：进行中、所有任务、累计消息、已记录 Token。
- 采用用户照片中的 0 / 33 / 1,082 / 3.2亿作为示例值；“有进行中任务”切换为 2，仅为交互演示。
- 黑底、系统字体、无大块卡片。应用标题移除；设置降低为次级入口。
- 点击进行中或所有任务进入对应页面。零个进行中时显示紧凑空状态，仍提供所有任务入口。
- 进行中详情支持左右滑动；最后一个任务再向左进入所有任务。Agent 名称与运行时间同一行。
- 完成任务进入结果页：结果直接阅读、朗读为顶部小图标、语音继续单独固定在底部。进行中不提供语音继续。
- 所有任务及较长结果可垂直滚动，无可见滚动条。
- Watch 导航独立于手机，不同步当前页或当前选中任务。
- 录音、朗读、发送及设置切换为本地界面演示，不调用设备或服务。

## 双栏总览

两个任务入口横向并列，下方两列累计统计；底部无填充的省略号打开设置。核心入口均一键直达，推荐优先选用。

## 焦点状态

进行中数量居中放大，所有任务为一行入口，下方并列累计统计。左右滑动切换统计页和次级页；底部页码及箭头提供可点击替代入口。次级页提供设置，可增加统计字段。

## 紧凑清单

四项统计纵向排列。前两行可点击，后两行为只读统计。首屏向上滑进入次级页，也可点击底部“更多”；次级页向下滑或点击返回回到首屏。新增统计字段放在次级页，可继续纵向滚动，不显示滚动条。

## watchOS 顶部约束

提案按用户期望省略时间及应用标题。当前 Xcode WatchOS SDK 中 `.statusBarHidden` / `.statusBar(hidden:)` 标为 watchOS unavailable，不能照搬 iPhone 的隐藏时间办法。`.toolbar(.hidden, for: .navigationBar)` 在 watchOS 可用，是待选方案实现时验证的路线；不使用 `_statusBarHidden` 等下划线 API。系统时间是否同时消失、导航是否影响返回行为以及各表型安全区，仍需 watchOS 真机验证，不能用此浏览器提案作为证明。若系统保留时间，只预留系统必须的顶部区域，仍保持四项核心统计一屏。

## 浏览器验证

- 224×272 与 252×306 两种演示尺寸下，三版首页 scrollHeight 均不超过 clientHeight。
- 320px 外部容器无水平溢出。
- 三版均检查：进行中空状态 → 所有任务 → 已结束任务 → 结果 → 语音演示 → 确认 → 发送；设置入口及返回。
- 有进行中任务时检查左右滑动、最后一页进入所有任务、Agent 与运行时间同行、无语音继续入口。
- 增加统计字段检查次级页面与返回；未知数值展示为破折号。
- JS 无运行错误；通过技能自带独立预览包装器检查真实图标和三版截图。
- 这些是浏览器交互与布局检查，不代表 watchOS 真机收音、朗读或布局验证。
