# 共享功能 UI 与交互调整原型

预览：http://127.0.0.1:3105/docs/prototypes/sharing-ui-refinement/

本轮只新增交互原型，不修改正式共享功能。页面 DOM、CSS 和字体采集自当前正式代码构建的 `/fusion` 页面；聊天正文保持原有字体、字重、字号和排版。`templates.json` 保存真实聊天及智能体页面结构，`assets/` 保存对应生产 CSS 与字体。

## 入口与归属

- 会话顶部保留 Share 图标，名称为“分享查看链接”，用于生成公开只读内容链接。
- 新增 Users 图标，名称为“邀请协作”，用于按账号授权参与当前会话。
- 有成员时显示头像组，点击管理协作者。实心头像表示已加入，虚线头像表示待接受；不表示在线、正在输入或正在执行。
- 自己共享的会话继续保留在个人项目中，侧栏会话后增加协作标记。移除单独“我共享的”列表。
- “协作会话”仅组织收到的会话。按“提供者 + 原项目”分组，界面显示项目名称和提供者，不显示内部 ID。不同提供者的同名项目不会合并。

## 邀请弹窗

使用固定标题“邀请协作”，会话名作为灰色单行摘要，长标题省略并可悬停查看。桌面端邮箱、权限、邀请按钮在同一行，成员管理紧接在下方；手机保持邮箱与权限并列，按钮移到下一行右侧。

成员行统一显示头像、名称、邮箱、权限及移除按钮。新邀请显示待接受状态，重复邮箱不新增。可协作表示现有 `execute` 权限，可查看表示 `view` 权限。共享智能体仍仅提供现有的使用权限，不新增只读 Agent 授权类型。

公开查看链接使用独立小弹窗和复制操作，不与邀请表单混在一起。

## 智能体列表

“我的智能体”和“共享给我”复用当前实际的同一表格结构、列宽、行高、头像及操作图标。共享来源和项目放在名称下方的辅助信息中；主列仍为智能体、运行环境、模型、状态。

自己的智能体保留共享及使用入口；收到的智能体提供查看能力和使用入口，待接受时先确认授权范围。收到的列表使用提供者来源说明，避免把个人 Relay 连接状态误当成共享能力的运行位置。

## 项目组织

侧栏和集中页面均使用“项目 → 会话”树形结构，以展开箭头、文件夹、缩进和选中状态建立层级。侧栏默认只展开第一组，减少导航拥挤；集中页面默认展开各组，支持按项目、会话和提供者搜索。

## 演示与验证

左下角演示说明与长标题测试按钮不属于产品 UI。数据均为虚构数据，只保存于浏览器内存；不发送真实邀请或执行任务。

可直接访问：

- `?dialog=invite`：邀请弹窗。
- `?view=agents&tab=received`：共享给我的智能体。
- `?view=collaboration`：项目分组的协作会话。

浏览器检查覆盖实际样式基线（14px 正文和输入、24px 输入框圆角）、查看链接与协作入口区分、头像管理、邀请和权限变更、长标题、统一 Agent 表格、提供者项目分组、待接受/只读会话和手机布局。截图见 `previews/`。
