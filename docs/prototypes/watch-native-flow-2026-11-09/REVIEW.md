# Watch 首页设置与独立任务分类

2026-11-09，修订后的可交互原型。本轮仅更新原型资料，未修改、构建或安装 native App。

## 最终导航

- 首页承担全局导航：进行中、所有任务、设置。
- 设置参照用户播客照片的位置，放在首页右上角；36px 深灰圆形底与低对比描边，灰色调节图标，点击区域 44×44。首页预留居中系统时间，不加 Steer 标题；设置页返回首页。
- 四项核心统计保持一屏显示，保守预留系统时间，不显示重复的 Steer 标题、不用大块卡片。
- 进行中分类从首页进入，返回首页。左右滑动只切换进行中的任务；第一页 / 最后一页停止，边界箭头禁用。仅一个任务时不显示分页控件。
- 进行中没有所有任务或设置入口；零个任务时只有空状态与返回首页。
- 所有任务从首页进入，返回首页。不再提供省略号菜单或设置。零进行中不显示该分组或占位。
- 所有任务里的运行任务打开独立详情，返回原列表，不跳到进行中分类。详情保留 Agent 与运行时间同行、最新指令，不提供语音继续。
- 已结束任务打开可滚动结果详情，返回原列表；朗读为右上角图标，语音继续固定在底部。
- 语音取消回原任务；录音 → 编辑确认 → 发送 → 等待执行。发送后返回原列表，不额外跳转另一分类。跨分类操作始终通过首页。
- 长列表和结果滚动时不显示滚动条。Watch 导航独立于手机。

## 演示范围

首页沿用照片中的 0 / 33 / 1,082 / 3.2亿；任务和回复为示例内容，列表仅展示有限样本。演示调节支持有进行中任务、较大屏幕和识别失败场景。

系统时间仅为安全空间预留，不是 watchOS 系统截图。语音、朗读、发送、识别及设置都是本地交互演示，不录音、不播放、不调用后端。

## 浏览器验证

通过 Chrome + Playwright 检查：

- 224×272 与 252×306 演示尺寸，零 / 有任务首页都无垂直溢出；320px 外部宽度无水平溢出。
- 首页设置可进入、返回；设置开关与语音选项可修改。
- 零任务和有任务的进行中页面均无所有任务 / 设置入口。
- 最后一个任务连续向左滑仍停在最后任务，不进入所有任务；两端箭头禁用。
- 两种分类都返回首页；所有任务中进入的运行 / 结束任务详情都返回原列表。
- 所有任务无设置 / 菜单；运行详情无语音与分页控制。
- 完成任务语音确认发送后返回原列表，对应任务转入进行中。
- JS 无运行错误。
- 使用技能包装器检查真实图标及首页、设置、零任务、列表、详情、语音截图。

这是浏览器原型验证，不代表 native watchOS 布局、收音或语音服务真机验证。
