# 协作会话 + 智能体共享 · 组合交互方案

日期：2026-10-26。基于用户确认的产品边界调整，只新增原型，不改正式应用。前三版保留于 `../personal-sharing/`。

## 导航与对象归属

- 每个人仍有自己的 Workspace、项目和私密会话。
- 侧栏「协作会话」是共享 Session 的唯一集中入口，分「我参与的 / 我共享的」。前者展示收到的邀请和已参与会话；后者展示所有者开放的会话并提供管理共享。
- 侧栏「智能体」页面分「我的智能体 / 共享给我」。共享出去的 Agent 仍留在我的列表，显示共享状态和管理入口；接收者只看到明确授权的 Agent。
- 共享 Agent 新建的独立 Session 归属于接收者，在其授权项目下出现，不自动加入协作会话区。需要共同推进时，再共享这个 Session。
- 打开协作 Session，顶部标明原所有者、项目和参与者，返回箭头回到集中列表。个人项目中的原会话仍是同一份工作。

## 原型可操作路径

1. 默认 Alex「我共享的」：打开 Session 或点击管理图标，输入邮箱、选择可参与/可查看，管理成员。
2. 顶部切换林悦：默认「我参与的」，接受并打开同一 Session，选择讨论或向 Agent 发任务。只读权限下禁止发送。
3. 协作会话列表提供搜索；切换「我共享的」可查看空态。不会把私密 Session 自动列入共享对象。
4. Alex 的智能体页：Reviewer → 共享能力，明确 Steer 项目、dev-machine / Claude Code、独立 worktree 和并发额度。发送后列表显示已共享及管理入口。
5. 林悦的智能体页：「共享给我」→ Reviewer → 查看能力 → 接受并开始聊天，个人侧栏增加独立会话。返回协作区后「我共享的」仍为空。
6. 查看访问权限与退出共享沿用右侧面板。原型不设单独共享收件箱，也不引入团队 Workspace。

## 界面规格

保持现有 Steer Logo、Geist 字体、264px 侧栏、860px 聊天阅读宽度、蓝色用户消息、Completed 状态栏、深灰主按钮和轻量列表。列表标题与状态保留清晰层级，操作按钮集中在右侧；手机改为自然换行布局。

正式实现应复用 Sidebar、ChatView、智能体页面、Dialog/Sheet 与 Button/Select，不复制原型模拟导航。顶部演示场景与身份切换只用于原型，不属于产品 UI。

## 演示边界与验证

邀请、权限、消息和 Agent 执行只修改浏览器内存，刷新会重置。默认预置一条 Alex → 林悦 的 Session 邀请，一项共享能力供流程演示，不发送实际通知、不修改实际代码。

Workspace 私有不代表提供者机器不可见：共享 Agent 的运行机器、文件和原生日志仍由提供者管理；该提示在使用确认中明确。目录授权、服务端权限、凭据与沙箱隔离需在正式开发时实现。

`previews/` 保存所有者/接收者列表、共享管理、协作 Session、Agent 使用确认、个人独立会话，以及手机布局。浏览器检查覆盖以上操作、列表搜索、只读与参与状态。旧版原型文件未覆盖。
