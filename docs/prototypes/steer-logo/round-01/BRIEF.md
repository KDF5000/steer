# Steer Logo — 第一轮概念设计

日期：2026-10-24。状态：概念比较，尚未替换正式产品 Logo。

## 品牌任务

Steer 是面向开发者与技术团队的 AI Agent 工作台，以对话组织项目、执行任务和多个 Agent 的接续协作。Relay 负责执行基础设施；Steer 的标志表达使用者的掌控与工作接续，不需要把机器、聊天和模型都画进去。

设计关键词：简洁、清晰、克制、可靠、有掌控感。使用场景以当前工作台侧栏 30 px、浏览器页签 16 px、官网标题和仓库说明为主。

现有 Logo 是深灰圆角方块中的 S，侧栏另以文字 S 呈现。保留 Steer 名称和深灰底色的熟悉感，探索更独特的符号；不更改已确认的聊天字体和输入框。

本轮假设：没有必须保留的旧字形，也没有需要先确定的品牌色。先用黑白比较几何，后续选定方向再研究颜色及正式字标。用户为最终选择者。

## 研究与候选

使用 logo-design skill 的开发工具和协作产品参考库，研究了 Framer、Pagekit、Zendesk、Logstash、Precursor 的结构；仅研究几何和小尺寸表现，不复制品牌形状。开发工具库中抽象、图形和组合标志较多，蓝色、容器、负空间和线条也很常见。

本轮避开：机器人头像、对话气泡加星光、通用代码括号、罗盘/方向盘插画、蓝紫渐变救场、普通字体的 S 直接换色。

词语关联：Steer → 掌控/转向；工作台 → 稳定/容纳；多 Agent → 接续/交接；名称 → S/双 e。优先找形状与名称、功能态度之间的交集。

## 构造与版本

- A：256 方形画布，40 单位左右留白，水平带与折返转角形成单一闭合轮廓；v2 统一上下两端与外侧边界，改善小尺寸的稳定感。
- B：256 方形画布，外弧半径 96、内弧半径 56；开口中的定位块与弧保持可见间距，v2 收小定位块以减少粘连。
- C：两个相同的 e 轮廓错位放置，v1 厚度 24；v2 将厚度调整为 20、扩大内侧空间，并修复轮廓交叠造成的白缝。

每轮 SVG 和测试结果分别保留，不覆盖有意义的几何版本。

## 如何判断

先比较黑白轮廓，再看 16 / 24 / 30 / 32 / 64 px 和当前侧栏中的效果。深色背景、单色、模糊、镜像和旋转用于暴露弱点，不是最终交付样式。

A 的风险是转折字形容易与其他 S 标志接近；B 的风险是开口弧属于常见科技符号；C 的风险是小尺寸的双字母比单符号更依赖辨认。

所有图形均为原创几何 SVG，无字体依赖、外链图片、渐变或滤镜。方案页中的 Steer 文本沿用现有产品字体，只用于比较侧栏语境，尚非定稿字标。参考库检查不能替代正式商标检索。

## 选择后的下一步

本轮遵循 logo-design 的概念检查点：先展示三个概念，再按所选方向制作完整 Logo kit。完整 kit 包括最终几何、颜色、单色/反白、字标组合、小尺寸版、favicon/app icon 和使用规范。选定前不批量生成或替换正式应用资产。
