# Steer Logo — 第三轮，不同风格

日期：2026-10-24。状态：风格探索。前两轮原样保留；正式产品 Logo 尚未替换。

## 方向变化

用户明确要求跳出 B/B2 的演变。本轮不使用开口圆弧加定位块的骨架，比较四种不同气质。

| 方案        | 类型/风格      | 概念                                      | 需要留意                                               |
| ----------- | -------------- | ----------------------------------------- | ------------------------------------------------------ |
| C1 柔线 S   | 亲和的字形符号 | 自绘流动的 S，圆润端部弱化工业感          | 仍可能接近常见 S 字形；定稿时扩展描边                  |
| C2 连笔字标 | 克制的字标     | 名称本身成为标志，两个 e 在横画处轻微连接 | 全名不能直接缩进 favicon，所选方向需要专门的小尺寸符号 |
| C3 结构 ST  | 工业风字母组合 | 首两字母构成模块化联字，保持结构和工具感  | 首版容易读成 5T，展示版已改转角帮助 S 辨认             |
| C4 折翼     | 轻巧的抽象符号 | 斜向笔画与倾斜翼面，表达推进和带领        | 仍可能被理解为播放/方向符号，适合后续继续提炼          |

探索长名单还包含：软体 s、手写连续带、纯字标、双 e 联字、ST 联字、折页标、交织模块、折翼。本轮取柔线 S、连笔字标、结构 ST 和折翼，以便比较亲和、极简、结构、轻巧四种品牌态度。

## 字形与许可

C1/C3/C4 为自绘几何。C2 以 Geist（620 字重）为基础，手动组织字距，并连接两个 e 的横画，转换为独立 SVG 路径；浏览或使用 SVG 不依赖字体文件。Geist 的 SIL Open Font License 1.1 已保存为 `FONT-LICENSE.txt`，来源为 https://github.com/vercel/geist-font/blob/main/OFL.txt 。

`b-wordmark-v2.svg` 是本轮字标主体，`b-v2.svg` 是仅用于小尺寸研究的 s 参考，不是已定稿 favicon。C2 在工作台预览中以字标替代顶部名称展示，聊天字体和输入框保持当前原版。

审计提示字标有原字体的微小斜向笔画；这些是字体的光学校正，不按符号的直线网格强行拉直。C1 暂时保留 SVG 描边以便低成本迭代；选定后应扩展为填充轮廓。

## 两轮构造

- v1/v2 均保留独立 SVG。
- C1：减少笔画厚度，重新平衡上下曲线及两端。
- C2：将轮廓路径坐标清理到小数点后两位，保留连笔及光学间距。
- C3：增加 S 的转角切面，避免最初的 5T 阅读；整体向左移动 4 单位保持水平居中。
- C4：将等腰三角改成折叠翼面，减轻播放按钮联想；以 15/45 度构造并水平居中。
