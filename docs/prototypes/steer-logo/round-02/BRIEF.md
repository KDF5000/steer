# Steer Logo — 第二轮，继续 B 方向

日期：2026-10-24。状态：概念比较。第一轮保留在 `../round-01/`，正式产品 Logo 未替换。

## 本轮目标

用户更喜欢第一轮 B 的方向，但尚未满意。本轮保留它的开放弧线和定位感，探索更安静、更稳定、更整体的几何。品牌定位、黑白优先、小尺寸及现有工作台使用场景沿用第一轮设计 brief。

选项探索包括：圆形锚点、方形锚点、菱形锚点、圆角方框、定位块并入圆弧、双弧接续、双层圆弧和负空间转向。圆形锚点与双层圆弧过于常见，菱形已在上一轮提供；负空间转向在小尺寸容易不清楚，因此制作以下四种方案。

| 方案    | 几何变化               | 特点                                 | 风险                                   |
| ------- | ---------------------- | ------------------------------------ | -------------------------------------- |
| B1 方位 | 圆弧加直立圆角方块     | 最接近原 B，更安静                   | 仍有常见圆环科技标志的感觉             |
| B2 弧窗 | 圆角方框加方形开口模块 | 轮廓稳定，与工作台界面协调           | 容易偏向通用应用图标，需要继续打磨个性 |
| B3 转折 | 定位块并入一条轮廓     | 更整体，没有两个零件的感觉           | 可能先被读作 C 或 G                    |
| B4 回环 | 两段相向弯折错位接续   | 保留圆弧，并隐约形成 S，与名称有关联 | 可能被理解为同步/循环符号              |

建议重点比较 B2 和 B4：B2 更接近用户偏好的 B，又比完整圆环稳定；B4 更强调 Steer 的名称与任务接续。推荐不是最终选定。

## 两轮几何版本

- `*-v1.svg`：本轮第一版构造。
- `*-v2.svg`：小尺寸及平衡调整后的展示版。
- B1 缩小方块至 56 单位，圆角 6；方块与圆弧端部的间距统一为 36。
- B2 外圆角从 56 调整为 64，内圆角从 20 调整为 28，框厚度保持 36；定位方块宽 52，与两侧端部间距均为 36。
- B3 缩短内侧竖向端部，开口从 16 扩为 24，避免 16 px 下过窄。
- B4 缩短水平端部，减轻两片之间的拥挤感。

所有标志均为纯几何 SVG，没有外链图片、字体、阴影或渐变。背景反白为测试处理，尚未制作最终颜色或完整资产 kit。
