# 报告页内编辑 · 2026-10-25

保存后的报告不再通过弹窗编辑。点击「编辑报告」，标题与 Markdown 正文在详情页原位置变成编辑区，右侧操作切换为取消和保存。正文编辑区按内容及视口宽度自动增高，沿用报告正文字体。

编辑状态独立于新报告生成草稿。保存沿用原报告 ID、日期、项目及来源；不关联新的生成任务。保存失败保留输入，取消恢复已保存报告，保存成功返回 Markdown 预览。

`before/` 保留上一版详情页截图；`after/` 包含桌面与手机的页内编辑和保存后预览截图。使用虚构演示数据和独立浏览器，不写入实际业务数据。

浏览器验证覆盖无弹窗、焦点进入正文、自动高度、标题及正文修改、保存失败保留草稿、取消恢复原文、成功保存及来源日期保持、手机布局。
