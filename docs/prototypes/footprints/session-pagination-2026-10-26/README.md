# 会话明细分页 · 2026-10-26

默认每页 10 条，可选 20 / 50 条。底部显示当前记录范围、总会话数、页码以及上一页/下一页。10 条以内保持原列表，不显示分页栏。复用现有 Button 和 Lucide 图标。

分页作用于日期、项目和每日下钻过滤后的会话明细，切换筛选或每页条数回到第一页。统计卡、趋势和报告生成仍使用完整筛选范围。已有 API 返回会话集合，翻页在前端完成，不额外请求汇总接口；数据传输量尚未改为服务端分页。

`before/` 保留上轮 Token 概览截图（两条会话示例）；`after/` 使用 25 条虚构会话展示真实 `/fusion` 桌面、手机分页效果，两组演示数据不同。不包含真实账户数据。

浏览器检查覆盖每页 10/20/50 条、末页和按钮禁用、日期及项目筛选重置、汇总与报告范围、翻页无额外请求和手机布局。
