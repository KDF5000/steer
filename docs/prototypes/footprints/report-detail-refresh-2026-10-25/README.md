# 足迹报告详情页调整 · 2026-10-25

`before/` 与 `after/` 保存正式 `/fusion` 页面在相同演示报告数据下的桌面（1440 × 1000）和手机（390 × 844）2x 截图。使用独立浏览器拦截演示 API，不包含真实用户内容。

调整：

- 详情容器与页签左侧对齐，移除内部重复居中缩进。
- 返回列表放在左侧工具栏，导出和编辑在右侧，使用现有 Button 的 ghost / outline 小号样式。
- 报告标题为 20px / 600（手机 18px），日期与来源为 12px，正文为 14px / 1.65，正文阅读宽度最多 860px。
- 正文沿用 WorkLogMarkdown；聊天和输入框字体没有改动。
- 结束日期显示范围内最后一天，排他查询边界仍保持不变。

本轮审查同时修正：报告输入缺少项目名称、用户消息采样与概览时间口径不同、保存缺少项目与来源校验、报告保存与生成任务确认不在同一事务、无效自定义日期导致页面报错。数据库专项回归验证筛选和隔离、时间边界、更新兼容、无效生成任务与保存回滚。

已知后续事项：报告生成仍依赖当前页面的轮询与草稿状态，刷新或离开足迹页面后的任务恢复需要补齐；全工作区报告没有统一的输入预算与分批汇总。旧工作日志数据和接口仍保留，当前导航已替换为足迹，旧记录的可见入口需要产品上明确。
