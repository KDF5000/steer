# 协作会话输入交互原型

预览地址：http://127.0.0.1:3105/docs/prototypes/collaboration-composer/

## 实际页面基线

本原型从当前本地 Docker 服务 `/fusion` 页面采集渲染后的 DOM、生产 CSS 和字体资源，使用虚构账号、项目及消息。没有重新绘制工作台，也没有调整聊天字体。`assets/actual-*.css` 为采集的样式，`interaction.css` 仅增加协作相关组件。

浏览器核对基线见 `actual-style-baseline.json`：输入框字体 14px、Agent 消息字体 14px、输入框圆角 24px。消息正文、蓝色用户消息、状态栏、操作图标和输入框沿用实际页面结构。

## 体验流程

1. 在原有输入框底部选择“发给 Agent”或“讨论”，切换时保留文字。
2. 发送讨论只新增参与者消息，不启动 Agent，也不自动成为 Agent 的上下文。
3. 点击讨论下的“交给 Agent”，输入框显示 `× | 引用 摘要` 并切换任务模式。补充要求后主动发送；已发送任务也展示引用摘要。
4. Agent 执行期间不能发起第二个任务，可以继续发送讨论。左下角“结束演示任务”模拟完成并展示结果。
5. 左下角可切换发言人，以及查看、讨论、执行权限。手机通过顶部“演示”打开控制面板。
6. 顶部“访问权限”解释本会话的访问范围。会话属于 Alex，个人 Workspace 不共享。

## 范围

这是用于评估输入交互的独立 HTML 原型。所有操作只修改浏览器内存，刷新重置；没有真实邀请、后台请求或 Agent 执行。原有页面中与本轮无关的按钮保留视觉呈现。

共享会话的集中管理与共享 Agent 入口见上一版 `../personal-sharing-combined/`。本版聚焦协作会话中的讨论、执行和显式引用，不改变已讨论的个人 Workspace 边界。

## 验证

浏览器验证覆盖生产样式基线、模式切换保留草稿、讨论发送、显式引用交接、任务串行与执行期间讨论、权限限制、手机宽度和演示弹窗。桌面与手机截图位于 `previews/`。
