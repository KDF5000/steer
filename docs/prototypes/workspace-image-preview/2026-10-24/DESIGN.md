# 图片预览：默认收起文件浏览

日期：2026-10-24。效果来自当前正式组件的浏览器渲染，接口和会话内容使用本地演示数据。

## 行为

- 从 Agent 回复打开 PNG / JPEG / GIF / WebP 图片时，文件浏览默认收起；加载期间也不会先闪现文件列表。
- 右侧预览工具栏的刷新按钮旁增加文件浏览展开/收起图标，悬停提示操作名称；`aria-expanded` 和 `aria-controls` 表达状态及目标。
- 文件浏览收起后，预览区域改为单列，图片获得原本用于目录列表的宽度。
- 手动展开/收起不丢失筛选文字和目录展开状态。
- 常规文本文件和主动打开 Files 的默认浏览行为保留；返回图片标签后仍默认收起文件浏览。

聊天字体、输入框、Logo 和图片全屏查看/下载行为不在本次调整范围内。
