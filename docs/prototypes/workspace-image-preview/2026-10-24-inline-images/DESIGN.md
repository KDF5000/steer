# Agent 回复中的工作区图片

日期：2026-10-24。界面截图来自正式组件的浏览器渲染，使用演示会话及模拟接口数据。

## 本轮调整

- Agent 使用 `![说明](图片路径)` 回复工作区图片时，消息中直接显示缩略图。
- 支持工作目录绝对路径、相对路径及 `file://`；绝对路径先转换为该次 Run 的实际工作目录内相对路径，再调用现有 Workspace 读取接口。
- 使用接口返回的 base64 图片数据展示，不让浏览器向 Web Server 请求 Node 上的文件路径。
- 同一条回复中的多张绝对路径图片共用一次工作目录查询；输入框更新不会重新读取已经显示的图片。
- 点击图片进入右侧预览，保留上一版“默认收起文件浏览”的交互。
- 加载时显示占位提示；读取失败显示说明及预览入口，避免破损图片图标。
- 普通 HTTP/HTTPS 图片按现有方式显示；危险 URL 仍通过 Markdown 的默认过滤。

聊天字体、输入框和 Logo 不在本轮调整范围内。使用 Relay 已支持的 PNG、JPEG、GIF、WebP 读取能力，不扩展后端的文件访问范围。

## 实现与核对

`app/fusion/page.tsx` 中的 Markdown 图片组件根据回复的 Run 读取图片；`app/fusion/fusion.css` 定义缩略图、占位和焦点样式；`lib/i18n.tsx` 提供中英文文案。
