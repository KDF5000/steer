# Steer 工作台视觉优化 — 02 保留原版聊天样式

版本：2026-10-24-02。此版是当前编码基准，已同步聊天字体和输入框回滚以及宽度对齐修复。

本目录是一版可直接打开的 HTML 设计预览。它提取当前 `app/fusion/page.tsx` 渲染的 DOM、Lucide SVG 和实际编译样式，并通过 `design.css` 覆盖本轮视觉调整。字体文件已经打包在 `assets/`，不依赖 CDN 或 Steer 后端。

项目名、Agent 名称及任务内容来自已有产品场景；账户、会话和耗时使用演示数据。预览中的发送、配置、删除和委派不会修改服务端数据，也不会执行真实 Agent。

## 设计范围

本轮调整左侧导航和聊天工作区，不重做 Runtime / Agent / Project 配置页面，不增加新的产品功能。

- 保留 Workspace、项目 → 会话、资产、工作日志、产物、系统设置和账户结构。
- 保留引用、mention、委派会话、执行详情、复制、重试、下载和分享入口。
- 会话列表优先显示任务名称，委派身份使用尾部小图标与完整 tooltip。
- 会话标题显示会话名称；完整工作目录保留在标题下方。
- 输入框下方使用机器名、Runtime 名和模型，不显示内部 Runtime ID。
- 聊天正文字体、Markdown 排版及输入框外观沿用原版，不跟随侧栏视觉调整。

## 生产实现对应位置

| 设计项                               | 实现位置                                                                             |
| ------------------------------------ | ------------------------------------------------------------------------------------ |
| 侧栏对比度、行高、缩进、选中与 hover | `app/fusion/fusion.css` 中 `.ws-sidebar`、`.ws-session-list`                         |
| 会话标题与委派来源标记               | `app/fusion/page.tsx` 的项目会话列表与 `ChatView` 标题                               |
| 正文、任务状态、操作栏、消息间距     | `app/fusion/fusion.css` 中 `.ws-chat-message`、`.ws-chat-response-*`                 |
| 输入框、引用栏及聊天字体（保持原版） | `.ws-chatbox`、`.ws-inline-composer`、`.ws-quote-token` 及 `.ws-markdown` 的既有规则 |
| 机器、Runtime、模型的可读信息        | `ChatView` 的 `.ws-chat-mode-note`                                                   |

会话标题优化需要使用任务内容作为摘要，并将 `@Agent` 元信息单独显示；不能仅用 CSS 隐藏一个前缀。既有会话名称不应自动永久重命名，可先在展示层优化。

## 交互与响应式验收

- 项目展开/收起；选中会话；委派会话进入与返回。
- 引用指定回复、移除引用保留文字、输入 `@` 选择 Agent。
- 任务状态展开/收起；回复图标准备主 Agent 草稿。
- 搜索、Agent 选择、输入换行与本地提交演示。
- 桌面折叠侧栏；手机按需打开侧栏。
- 桌面/手机没有横向溢出；输入框保持可用；长内容可以在聊天区域滚动。
- `prefers-reduced-motion` 下不播放旋转动效。

右下角“设计规格”是预览辅助工具，不属于正式产品 UI。预览中配置入口的说明弹窗也不属于正式页面改动。

## 本地预览

```bash
python3 -m http.server 3104 --bind 127.0.0.1 \
  --directory docs/prototypes/workbench-visual-refresh
```

打开 `http://127.0.0.1:3104/`，也可以直接用浏览器打开 `index.html`。后续按本目录编码时，应保留实际业务逻辑、权限校验、项目机器限制以及已有的原生会话处理机制。

导出的 `index.html` 保留实际 DOM 的紧凑序列化形式，避免 HTML 自动缩进改变 `white-space: pre-wrap` 文本和 contentEditable 中的可见空白。维护时优先修改 `design.css` 和 `app.js`。
