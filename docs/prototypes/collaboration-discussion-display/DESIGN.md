# 讨论消息在聊天区域中的展示

预览：http://127.0.0.1:3105/docs/prototypes/collaboration-discussion-display/

本轮仅比较参与者讨论的呈现方式，输入框沿用已确认的“讨论 / 发给 Agent”切换。三种方案使用同一组虚构消息、实际工作台 DOM、生产 CSS 及字体，保留 Agent 正文、用户任务消息和输入框样式。

| 方案 | 呈现 | 取舍 |
| --- | --- | --- |
| A · 开放消息 | 左侧头像、作者、时间，下方正文；无气泡或容器 | 外观最简洁，与 Agent 正文主要通过作者栏区分 |
| B · 灰色消息 | 同样的作者栏，正文放在浅灰气泡中 | 讨论、蓝色任务指令、Agent 回复更容易辨认，容器略多 |
| C · 连续讨论组 | 相邻讨论合并进同一组，显示参与者和条数，可收起 | 大量讨论时更省空间，增加分组层级 |

每条讨论都可点击“交给 Agent”，引用其正文并准备任务输入。讨论本身不会触发执行或自动进入 Agent 的上下文。C 遇到 Agent 任务或回复会结束上一组，此后的讨论另起一组；收起时展示最后一条讨论摘要。

顶部方案切换、左下角发言人及任务模拟控件仅用于原型比较。所有操作使用浏览器内存，不发送真实消息、不调用 Agent、不改变个人 Workspace 的权限边界。

验证包含 14px 输入及 Agent 消息字体、24px 输入框圆角的实际基线、三种方案混排、引用交接、执行期间讨论、C 分组与收起、手机宽度。截图位于 `previews/`。
