# Build 16 验证记录

布局变化：Watch 统计概览 → 进行中分页／所有任务列表 → 直接阅读结果。结果操作分为顶部朗读图标和底部固定语音主按钮；正文中没有「展开结果」「朗读结果」大按钮。

统计范围：任务数为工作空间未归档会话的最新任务数量；消息数按现有 Footprints 非空 user／agent 消息计算；Token 使用已有已结束 chat 的规范化用量数据，与 Footprints 共享聚合逻辑。无用量记录返回 null，区别于实际记录为零；系统报告和重复 attempt／镜像执行不重复计入 Token。

验证通过：

- 25 项 Swift 核心测试，包括统计 null／0 区别、数字格式和账号缓存编码。
- API 权限、工作空间 Header 不覆盖密钥工作空间、分页参数及空页检查。
- PostgreSQL 用量测试：与 Footprints 一致、部分／缺失记录、排除系统报告、重复 attempt 和父会话镜像不重复计费。
- 原生 UI 测试宿主：手机聊天交互、Watch 概览（进行中为零）→ 空状态 → 返回 → 所有任务 → 长结果阅读、语音按钮可点击，以及语音无配对手机时的错误／重试路径。
- iPhone 与嵌入的 Watch App 签名构建，后端 Docker 更新及健康检查。

UI 宿主使用隔离的 iOS 模拟器、固定数据及不可用 Watch 硬件类型桩，直接编译 Watch 视图源码。它用于验证交互状态，不作为 watchOS 字体、实际屏幕间距、麦克风或真实音频播放的验证证据。本机仍没有 watchOS 模拟器 runtime。
