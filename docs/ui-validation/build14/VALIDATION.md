# Build 14：手机任务详情对齐 Steer 聊天页

参照 `app/fusion/page.tsx` 的 ChatView 与 `app/fusion/fusion.css` 中的聊天规则，在原生 SwiftUI 中实现标题/项目顶部栏、靠右用户消息、无卡片 Agent 正文、消息操作图标、输入区 Agent/模型上下文和执行中停止按钮。

模型与每轮 Agent 信息来自已有聊天历史 context，仅展示 API 实际返回的数据。本版没有新增 Agent/模型选择或附件上传接口。用户消息仍可展开；两端导航独立。进行中输入禁用，但可保留草稿和停止执行；只有成功结束的任务允许发送新回复，未确定的提交可按原 idempotency key 重试。

24 项 Swift 核心测试通过，新覆盖历史格式兼容性、每轮模型/作者、引用和错误字段。iPhone 及嵌入的 Watch App 签名构建通过。

隔离 iOS 原生 UI 测试通过：任务列表 → 对话 → 长提问展开/收起 → 回到最新消息 → 复制反馈 → 键盘输入 → 返回 → 运行中任务。验证了运行中输入禁用及停止入口，测试未发送或停止真实任务。

PNG 为原生 iPhone 模拟器截图，使用固定数据和隔离内存存储，并非设计稿或真实账号截图。该数据集不包含 model 字段，截图中没有虚构模型名。

当前设备使用 iOS 27。iOS 18+ 使用系统滚动几何回调；iOS 17 使用底部锚点生命周期作为兼容回退，尚未在 iOS 17 真机验证。
